\# 🏓 Pong Game



A simple \*\*2-player Pong game\*\* made in \*\*C#\*\* using the Console.



\## 🎮 Controls



\* \*\*Left Player:\*\* `W` / `S`

\* \*\*Right Player:\*\* `↑` / `↓`



\## 🎯 Goal



Hit the ball with your racket and prevent it from passing your side.



The first player to reach \*\*5 points wins\*\*.



\## 🛠️ Built With



\* C#

\* .NET Console

\* `Console.SetCursorPosition()`

\* `Console.ReadKey()`

\* Basic collision detection and game loops



\## ▶️ How to Run



Open the project in Visual Studio or another C# IDE and run `Program.cs`.



Have fun! 🏓
